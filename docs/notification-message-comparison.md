# Tinzel notification message comparison

Updated 1 November 2026. These are message templates, not messages sent to real recipients. Braced values are populated from the saved account/order. Credential and OTP placeholders must never be replaced with real secrets in this document.

All customer/staff links default to https://tinzel.stryxis.com. Staff use /staff or their permitted order workspace; customers use /track and authenticate there. Printer documents retain protected, signed backend URLs in WhatsApp; the SMS directs the printer to WhatsApp. Saved recipient language determines English or Kiswahili.

The old column is captured from the previous active templates; older workflow messages appended the configured action link, which fell back to localhost when FRONTEND_URL was missing. Account examples use the Manager role; live messages display each recipient’s actual Administrator, Manager or Designer role and corresponding responsibilities. Manager rows apply to all active managers and administrators, with the actual role shown in the message. No real password, code or signature is included below. Payment amount/reference and correction round/count appear only when recorded. Historical notifications are unchanged.
